## The service

NoteFill adds numbered endnotes to the document you open it in. It writes a reference number at
the cursor and lists the notes under a heading at the end of the document, or of each tab. Each
reference links to its note and each note links back. It renumbers the notes in the order of
their references, converts the document's footnotes to endnotes, and removes a note you choose.

Each renumber rewrites the reference numbers and **the list of notes under its heading**, and
puts a bookmark at each reference and each note for their links. Docs shows these bookmarks as
small blue markers while you edit. Anything you write after the heading stays with the note it
follows. **A note whose reference has been deleted is removed on the next renumber, and so is its
text.** Converting replaces each footnote with an endnote reference and moves its text to the
list; NoteFill cannot turn endnotes back into footnotes. **File > Version history** in Docs shows
the document as it was before any of these, and restores it.
