## The service

CodeFill highlights code in the document you open it in, as you ask. **Lines you select become a
block**: the paragraphs are replaced by a one-cell table holding the same text, one line per
paragraph, in the font, size and colors you chose, on a shaded background. Blank lines at the
start and end of the selection are dropped, and the lines' own formatting (headings, list bullets,
indents, links) is not kept. **A snippet you paste in the sidebar** is inserted as a new block
after the paragraph your cursor is in. **Highlighting a block again** rewrites its font and colors.
CodeFill marks each block with a named range so it can recognize it later. **Edit > Undo** and
**File > Version history** in Docs show and restore the document as it was before.

CodeFill highlights with highlight.js, open-source software under the BSD 3-Clause License, whose
license is in the add-on and at [pikoulas.com/codefill/licenses](/codefill/licenses/). Automatic
language detection can be wrong; choose the language in the sidebar if it is.
