## The service

QRFill makes QR codes for the form you open it in: one with the form's own link, or a set with
one prefilled link per answer to a question you choose. It draws them in your browser, for you to
download as PNG or SVG files or to print.

Codes link straight to your form and never expire: each holds the form's link itself. They open
the form for as long as that link works, so deleting the form, or unpublishing it, stops them
opening it. A prefilled answer is only a starting point; the person answering can change it.
QRFill does not submit answers, host links or count scans.

QRFill changes your form only if you click **Add a sample question**: it then adds a dropdown
question "Table" with three choices at the end of the form, which you can delete there.

**Scan a code before you print many**, and check it opens the form you meant, with the answer you
meant. Colors, a logo, a small print size or a worn print can make a code harder for some phones to
read.
