## The service

ContentsFill shows an outline of the tabs and headings of the document you open it in, moves the
cursor to a heading you click, and writes a linked table of contents into that document.

When you insert the table, ContentsFill adds a one-cell table below the paragraph with the cursor
and writes the contents into it. It puts a bookmark at the start of each heading the table lists,
which the table's links go to; Docs shows these bookmarks as small blue markers while you edit.
**Refresh replaces everything inside the table** with the current contents, so anything typed
into the table is lost on the next refresh; text outside it is never changed. A document has one
ContentsFill table. **Remove table and bookmarks** deletes the table and the bookmarks ContentsFill
added; your headings and text stay as they are. **File > Version history** in Docs shows and
restores the document as it was before any of these.
