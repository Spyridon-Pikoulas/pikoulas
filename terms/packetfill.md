## The service

PacketFill fills a local ordinary named-field AcroForm PDF using rows in the current spreadsheet.
You select the source, map fields, choose how unmapped editable fields are handled and review
filled pages. It leaves source cells and the original PDF unchanged, and prepares one flattened
PDF per record in a ZIP. Processing happens in your browser using data read from Google's services.

Supported fields are plain text, comb text, checkboxes, single-choice dropdowns and radio groups.
The output is static: form fields, action buttons and signature widgets are no longer interactive.
PacketFill does not complete signatures, submit or email forms, calculate field formulas, run PDF
scripts or verify that the information you enter is correct.

Input limits are 5 MiB, 20 pages and 1,000 terminal fields. Each job supports up to 50 records,
30 source columns and 50 MiB total PDF bytes per ZIP, with further source-text and font limits.
Scans/flat PDFs, XFA, encrypted or signed/certified documents, rich-text, multiselect and
script-dependent forms are unsupported. A blank signature field is not a signed document; it is
left blank and removed as an interactive field from the static output.

Review all records, filenames and pages before generating, and check the downloaded documents
before using them. Unsupported text, invalid typed values or content that will not fit must be
fixed before output. Google's service limits and availability apply to free and paid use.
