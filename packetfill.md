## Fill the form you already use

- Read selected cells or explicitly use the current tab's used range. Choose whether the first
  row contains headings.
- Use ordinary fillable AcroForms with existing named fields. Search field names and map them
  to columns, without positioning text on a page.
- Keep displayed identifiers with leading zeroes. Fill text, checkboxes and single-choice fields.
- Choose whether unmapped editable fields keep their existing values or clear. Read-only values
  stay unchanged.
- Check text fit, supported characters, choice values and unique output filenames before output.
  Overlong values give a record/field error instead of silently spilling into the next box.
- Review the actual filled pages for every record. Download one flattened PDF per row, with
  all pages preserved, in a single ZIP.

## Or start from a Google Docs™ template

- Write tags such as `{{Name}}` where each column's value goes, in the body, headers,
  footers, tables or any tab. The template's own formatting is kept.
- Choose the Doc with Google's file picker. PacketFill lists tags without a column, and
  columns no tag uses, before anything runs.
- Preview the first row free. Name each PDF from a column; download a ZIP or save the PDFs
  in a new or chosen Drive folder.
- Up to 200 rows per run, about 50 PDFs a minute. Stop and go on later without paying twice.
- "Make a sample" adds a tab and a certificate template to try it on.

## Your files stay with you

Sheet values come from Google's services; form PDFs are filled, previewed and zipped in your

## Details

Supported input is a local, unencrypted ordinary AcroForm: up to **5 MiB**, **20 pages** and
**1,000 terminal fields**. A job can contain up to **50 records**, with at most **50 MiB of PDF
bytes** in its ZIP. Source limits also include 30 columns, 1,530 cells including headings and
1.5 million text characters. Text and comb fields, checkboxes, single-choice dropdowns and radio
groups are supported. Text must
fit at the chosen font size; bundled font coverage includes Latin and Greek. Technical and
Google service limits apply to free and paid use.

Scans, flat PDFs without fields, XFA, encrypted or signed/certified documents, rotated pages or
widgets, rich-text, multiselect and script-dependent forms are outside the supported workflow.
A PDF that looks fillable can still use an unsupported form technology. PacketFill checks input
before generation.
Output is static: fields, action buttons and blank signature widgets are no longer interactive.
PacketFill does not sign, submit, email or calculate forms, or run PDF scripts. Check the completed
documents before using them.

If a batch exceeds the remaining free outputs, select fewer records or unlock; PacketFill does
not silently omit rows. A 13-page PDF counts as one output, and the ZIP is only its package.

Generation counts when completion is recorded, rather than when your operating system confirms
a saved file. A repeated download or recognized retry of the same unchanged latest job does not
use the allowance again. After reopening, reselect its PDF, rows and options to regenerate it.
The latest retry record has no automatic expiry. Starting a different batch that passes the
source and allowance checks replaces it before completion. **Forget retry history** removes it
without restoring free usage or removing the purchase.
